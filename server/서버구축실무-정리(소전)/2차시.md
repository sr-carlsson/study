# Telnet 서버 구축
1. TCP 3-Way Handshake<br>
클라이언트 --TCP SYN-> 서버<br>
        <-TCP SYN ACK- <br>
        --TCP ACK --><br>
2. 옵션 협상
    1. WILL 송신 측이 해당 옵션을 활성화하겠음을 알림
    2. WONT 송신 측이 해당 옵션을 활성화하지 않겠음을 알림
    3. DO 수신 측에게 해당 옵션의 활성화를 요청함
    4. DONT` 수신 측에게 해당 옵션의 비활성화를 요청함

# Telnet 서버 구축

dpkg -l | grep telnet으로 현설치된 telnet 관련 패키지 목록 확인<br>
sudo apt install xinetd telnetd 으로 슈퍼 데몬과 telnetd 서버 설치<br>
sudo vi /etc/xinetd.d/telnet 로 telnet 서비스 설정 파일 생성 및 편집<br>

service telnet<br>
{<br>
		disable         = no                  # 서비스 활성화<br>
    flags           = REUSE               # 소켓 재사용 허용 (빠른 재시작)<br>
    socket_type     = stream              # TCP 방식 사용<br>
    wait            = no                  # 동시에 여러 연결 허용<br>
    user            = root                # telnetd 프로세스 root 권한으로 실행<br>
    server          = /usr/sbin/telnetd   # telnet 처리 프로그램 경로<br>
    log_on_failure  += USERID             # 로그인 실패 시 사용자 ID를 로그에 기록<br>
    bind            = 0.0.0.0             # 모든 네트워크 인터페이스에서 접속 허용<br>
}<br>

# SSH
1. TCP 3-Way Handshake<br>
클라이언트 --TCP SYN-> 서버<br>
        <-TCP SYN ACK- <br>
        --TCP ACK --><br>
2. 버전 협상<br>
서로 지원하는 SSH 프로토콜 버전 교환<br>
3. 알고리즘 협상<br>
    1. 키 교환 알고리즘<br>
    2. 서버 인증 알고리즘<br>
    3. 암호화 알고리즘<br>
    4. MAC 알고리즘<br>
    5. 압축 알고리즘<br>
4. 키 교환<br>
Diffie-Hellman 알고리즘을 통해 세션 키를 생성한 후, 서버는 공개키를 전송<br>
5. 서버 인증<br>
클라이언트가 서버의 공개키를 검증한 후, ~/.ssh/known_hosts 에 공개키 저장<br>
6. 사용자 인증<br>
7. 채널 오픈 및 세션 시작<br>

# SSH 서버 구축

dpkg -l | grep ssh  현재 설치된 ssh 관련 패키지 목록 확인<br>
<br>
sudo apt install openssh-server  SSH 서버 설치<br>
<br>
sudo ufw allow 22/tcp  방화벽에서 22번(SSH) 포트 허용<br>
sudo ufw reload  방화벽 재시작<br>
<br>
sudo vi /etc/ssh/sshd_config # SSH 서비스 설정 파일 생성 및 편집, 포트 수정 가능<br>

# 리눅스 계정 관리
1. groupadd<br>
	기본 그룹 생성 -g GID 지정<br>
				 -r 시스템 그룹으로 생성<br>
2. useradd<br>
   기본 계정 생성	-m 홈 디렉터리 자동 생성<br>
				-d 홈 디렉터리 경로 지정<br>
				-s 쉘 지정<br>
				-g 그룹 지정<br>
				-G 보조 그룹 지정 (복수 가능<br>
				-u UID 지정<br>
				-r 시스템 계정으로 생성<br>
				-e 계정 만료일 지정<br>
3. usermod<br>
	계정 수정<br>
4. passwd<br>
 	비밀번호 설정 -l<br>
				-u<br>
5. chage<br>
 	비밀번호 정책 설정	-m 비밀번호 최소 사용 기간<br>
					-M 비밀번호 최대 사용 기간<br>
					-W 만료 전 경고 일수<br>
					-I 만료 후 비활성화까지의 유예 기간<br>
					-E 계정 만료일<br>
					-l 현재 설정 확인<br>
<br>
chmod	파일 권한 변경	chmod 755 파일명<br>
								-소유자 - 그룹 - 기타 사용자<br>
								-4(r, 읽기) - 2(w, 쓰기) - 1(x, 실행)<br>
						chmod u+x 파일명 소유자 실행 권한 추가<br>
						chmod u-x 파일명 소유자 실행 권한 제거<br>
						chmod g=rx 파일명 그룹에 읽기, 실행 권한 허용<br>
						<br>
chown	소유자/그룹 변경	chown 사용자명 파일명<br>
						chown 사용자명:그룹명 파일명<br>
						chown -R 사용자명:그룹명 디렉터리<br>
chgrp	그룹 변경<br>
<br>
- /etc/passwd 계정 정보 (UID, GID, 홈, 쉘)<br>
- /etc/shadow 비밀번호 및 정책 정보<br>
- /etc/group 그룹 정보<br>
- /etc/sudoers sudo 권한 설정<br>
- /etc/skel/ 계정 생성 시 홈 디렉터리에 복사되는 기본 파일<br>
