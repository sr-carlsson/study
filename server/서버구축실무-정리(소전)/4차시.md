# Docker  
<h2>Docker</h2>
<h3>컨테이너를 쉽고 일관되게 만들고 실행할 수 있게 해 주는 플랫폼</h3>
Docker Engine :  컨테이너를 관리 및 운영하는 역할<br>
    - Docker Daemon : Docker API 요청을 수신하고 Docker Object 생성 및 관리<br>
    - Docker CLI  :  사용자가 이용하는 Docker 명령 (Docker Daemon 제어)<br>
    - Docker API  :  Docker Daemon을 지시하기 위해 사용하는 API<br>
Docker Object  :  Docker Daemon에 의해 생성, 관리되는 객체<br>
    - Docker Image : 컨테이너를 생성하기 위한 읽기 전용 템플릿 (정적 파일)<br>
        - 여러 개의 읽기 전용 레이어로 구성<br>
        - Base Image  : 기본 레이어<br>
        - Intermediate Layer  : 베이스 이미지 위에 추가되는 레이어<br>
        - Final Layer  : 컨테이너를 실행하기 위해 필요한 모든 파일과 설정<br>
        - 읽기-쓰기 레이어<br>
    - Docker Container  : 이미지의 실행 가능한 인스턴스 (동적 인스턴스)<br>
    - Docker Network  : 컨테이너 간 연결을 돕는 논리적 네트워크<br>
    - Docker Volume  : 컨테이너와 운영 체제 간 데이터를 공유하고 저장하기 위한 기능<br>
        - DB 데이터 및 로그 저장에 활용<br>
- Docker Registry  : 도커 이미지를 사용자 간 공유할 수 있도록 하는 플랫폼.   https://docs.docker.com/registry/<br>
    - Docker Hub  : 도커에서 관리하는 도커 레지스트리.   https://hub.docker.com/<br>
