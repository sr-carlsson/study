# Docker

## Docker

### 컨테이너를 쉽고 일관되게 만들고 실행할 수 있게 해 주는 플랫폼

Docker Engine : 컨테이너를 관리 및 운영하는 역할

* Docker Daemon : Docker API 요청을 수신하고 Docker Object 생성 및 관리
* Docker CLI : 사용자가 이용하는 Docker 명령 (Docker Daemon 제어)
* Docker API : Docker Daemon을 지시하기 위해 사용하는 API

Docker Object : Docker Daemon에 의해 생성, 관리되는 객체

* Docker Image : 컨테이너를 생성하기 위한 읽기 전용 템플릿(정적 파일)

  * 여러 개의 읽기 전용 레이어로 구성
  * Base Image : 기본 레이어
  * Intermediate Layer : 베이스 이미지 위에 추가되는 레이어
  * Final Layer : 컨테이너를 실행하기 위해 필요한 모든 파일과 설정
  * 읽기-쓰기 레이어

* Docker Container : 이미지의 실행 가능한 인스턴스(동적 인스턴스)

* Docker Network : 컨테이너 간 연결을 돕는 논리적 네트워크

* Docker Volume : 컨테이너와 운영 체제 간 데이터를 공유하고 저장하기 위한 기능

  * DB 데이터 및 로그 저장에 활용

* Docker Registry : 도커 이미지를 사용자 간 공유할 수 있도록 하는 플랫폼

  * https://docs.docker.com/registry/

* Docker Hub : 도커에서 관리하는 도커 레지스트리

  * https://hub.docker.com/

# Docker Compose

> 여러 개의 컨테이너를 정의하고 실행하기 위한 도구

## 장점

* Docker보다 간결한 문법 제공
* 컨테이너 간 연결이 쉬워짐
* `compose.yml` : Docker Compose 설정 파일

## Docker Compose 활용 단계

1. Dockerfile 작성
2. docker-compose.yml 서비스 정의
3. docker-compose 실행

---

# compose.yml

| 키/옵션          | 설명                                    | 예시                                   |
| ------------- | ------------------------------------- | ------------------------------------ |
| `version`     | compose.yml 파일의 명세 버전                 | `version: "3.9"`                     |
| `services`    | 컨테이너를 실행하기 위한 단위                      | `services: app:, db:`                |
| `image`       | 컨테이너의 베이스 이미지 지정                      | `image: postgres:16-alpine`          |
| `build`       | Dockerfile을 이용하여 컨테이너 생성              | `build: .`                           |
| `command`     | 컨테이너 내에서 실행할 명령어 지정                   | `command: npm run dev`               |
| `links`       | 컨테이너를 다른 컨테이너와 연결                     | `links: - db`                        |
| `volumes`     | 컨테이너에 볼륨을 마운트                         | `volumes: - ./data:/var/lib/data:ro` |
| `environment` | 환경 변수 설정                              | `environment: - NODE_ENV=production` |
| `ports`       | 컨테이너에서 호스트와 통신할 포트 지정                 | `ports: - "3000:3000"`               |
| `expose`      | 호스트에 노출하지 않고 연결된 컨테이너끼리만 접근 가능한 포트 지정 | `expose: - "5432"`                   |

# Docker Compose 명령어

| 명령어                      | 설명               | 옵션               |
| ------------------------ | ---------------- | ---------------- |
| `docker compose up`      | Docker 실행        | `-d` : 백그라운드 실행  |
| `docker compose start`   | 정지된 모든 컨테이너 실행   |                  |
| `docker compose restart` | 모든 컨테이너 재실행      |                  |
| `docker compose stop`    | 실행 중인 모든 컨테이너 정지 |                  |
| `docker compose down`    | 모든 컨테이너 정지 후 삭제  |                  |
| `docker compose logs`    | 모든 로그 출력         | `-f` : 실시간 로그 출력 |

# Docker 명령어

| 명령어                       | 설명                     | 옵션                                                                                                               |
| ------------------------- | ---------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `docker ps`               | 실행 중인 컨테이너 목록 확인       | `-a` : 모든 컨테이너 출력                                                                                                |
| `docker container start`  | 컨테이너 시작(백그라운드)         |                                                                                                                  |
| `docker container stop`   | 컨테이너 정지                | `-t` : 몇 초 후 정지할 것인지 지정                                                                                          |
| `docker container create` | 이미지로부터 컨테이너 생성         |                                                                                                                  |
| `docker container run`    | 컨테이너 실행                | `--name` : 컨테이너 이름 지정<br>`-d` : 백그라운드 실행<br>`-p` : 포트 연결(Host:Container)<br>`-i` : 표준 입력 활성화<br>`-t` : TTY 모드 사용 |
| `docker container rm`     | 정지 상태의 컨테이너 삭제         | `-f` : 실행 중인 컨테이너 강제 삭제                                                                                          |
| `docker image pull`       | Docker Hub로부터 이미지 내려받기 |                                                                                                                  |
| `docker image rm`         | 이미지 삭제                 | `docker rmi`                                                                                                     |
| `docker image ls`         | 내려받은 이미지 목록 확인         | `docker images`                                                                                                  |
| `docker build`            | Dockerfile을 통해 이미지 생성  | `-t` : 이미지 이름과 태그 지정                                                                                             |
| `docker attach`           | 동작 중인 컨테이너 접속          |                                                                                                                  |
| `docker exec`             | 컨테이너 외부에서 접근하여 코드 작동   |                                                                                                                  |

# Dockerfile

> 도커 이미지를 생성하기 위한 스크립트(설정 파일)

| 명령어       | 설명                              | 예시                                                 |
| --------- | ------------------------------- | -------------------------------------------------- |
| `FROM`    | 베이스 이미지 지정                      | `FROM node:20-alpine`                              |
| `RUN`     | 명령을 실행하여 이미지에 포함                | `RUN apt-get update && apt-get install -y curl`    |
| `WORKDIR` | 작업 디렉터리 설정                      | `WORKDIR /app`                                     |
| `COPY`    | 호스트에 있는 파일을 컨테이너 파일 시스템으로 복사    | `COPY package*.json ./`                            |
| `ADD`     | 파일 또는 디렉터리를 컨테이너로 복사(Remote 가능) | `ADD https://example.com/config.tar.gz /etc/myapp` |
| `USER`    | 컨테이너 내에서 명령을 실행할 유저, 유저 그룹 설정   | `USER node`                                        |
| `VOLUME`  | 컨테이너 내 특정 디렉터리를 컨테이너 외부 경로에 마운트 | `VOLUME ["/var/lib/mysql"]`                        |
| `CMD`     | 컨테이너 시작 시 실행할 커맨드 지정            | `CMD ["node", "server.js"]`                        |
| `EXPOSE`  | 트래픽을 특정 포트로 받아들일 수 있도록 지정       | `EXPOSE 8080`                                      |
| `ENV`     | 환경 변수 설정                        | `ENV NODE_ENV=production`                          |
