# RDP
RDP(Remote Desktop Protocol)는 TCP/IP 기반의 원격 데스크톱 통신 프로토콜로, 서버의 화면 정보와 사용자의 키보드·마우스 입력을 전송한다.<br>
클라이언트와 서버는 X.224를 통해 초기 연결을 수립한 후, TLS(Transport Layer Security)로 암호화된 통신 채널을 생성한다.<br>
이후 NLA(Network Level Authentication)를 통해 사용자 인증을 수행하고, MCS(Multipoint Communication Service)가 가상 채널을 생성하여 데이터를 송수신한다.<br>
이를 통해 원격 데스크톱 세션을 안전하고 효율적으로 제공할 수 있다 <br>

# 가상화 (Hypervisor & Container)
가상화
- 하나의 물리적 컴퓨터에서 가상 환경을 생성하여 컴퓨팅 환경 전체에 자원을 분산함으로써 자원을 보다 효율적으로 사용할 수 있게 해주는 기술<br> = 물리적인 하드웨어 자원을 소프트웨어적으로 추상화하여 하나의 물리적 자원을 여러 개의 독립적인 가상 자원처럼 사용
<br>
<br>
호스트 OS 가상화
- 하드웨어 위에 OS를 설치하고 그 위에서 가상화 소프트웨어, 가상머신이 움직임
<br>
- Host OS : 물리적인 하드웨어 위에서 직접 동작하는 OS <br>
- Guest OS : Host OS 위에서 동작하는 가상화 머신에 설치된 OS<br>

Hypervisor
- 여러 개의 OS가 단일 하드웨어 호스트를 공유할 수 있도록 하는 프로그램<br>
<br>
- Type 1 : 호스트 하드웨어에서 Hypervisor 구동<br>기업 서버나 데이터 센터에서 사용(성능up 보안up 부하down) Bare-metal 하이퍼바이저</br>
- Type 2 : Host OS에서 Hypervisor 구동<br>개발자나 개인 사용자에게 적합(부하down 다양성up 제약down) Hosted 하이퍼바이저<br>
<br>
전가상화와 반가상화<br>
- 전가상화 : Guest OS가 요청하는 모든 명령들을 Hypervisor가 번역하여 하드웨어에게 전달<br>(호환성up 오버헤드up 성능down) 하드웨어를 완전히 가상화<br>
- 반가상화 : Guest OS의 커널을 직접 수정하여 Hypercall API를 통해 명시적으로 요청<br>(호환성down 오버헤드down 성능up) 하드웨어를 부분적으로 가상화<br>
