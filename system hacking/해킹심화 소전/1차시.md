```
#include <stdio.h>

int main(void) {
   int num = 0x123456;
   char buf[16] = {};

   printf("Input : ");
   scanf("%s", buf);
   printf("Output : %s\n", buf);

   printf("Num: 0x%x\n", num);

   return 0;
}
```
해당 코드를 test.c로 저장한 뒤<br>터미널에 해당 명령을 입력하면
```
gcc -g -o test test.c -no-pie -fno-stack-protector
```
다음과 같이 test.c가 디컴파일된 test 파일이 생성된다.<br>
